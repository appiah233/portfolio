# Eric Appiah Owusu — Portfolio

Personal portfolio for Eric Appiah Owusu, presenting work across Microsoft 365, identity and access management, automation, cloud operations, and software engineering.

Built with Next.js 15, React 19, and Tailwind CSS 4. The design began from the [Nim template](https://github.com/ibelick/nim) and has been substantially redesigned.

## Local development

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Checks

```bash
npm run lint
npm run build
```

Project descriptions and links are maintained in `app/data.ts`. The featured JB Heights project is private, so this site intentionally does not link to its repository. Direct inquiries and consultation requests route to `info@ericappiah.com`. To enable direct calendar scheduling, set `NEXT_PUBLIC_BOOKING_URL` in the deployment environment and rebuild. The booking link should point to your real Calendly, Microsoft Bookings, or equivalent page.

## Contact & Call to Action

Inquiries, project requests, and consultation bookings are routed directly to `info@ericappiah.com`.
The site includes a one-click copy and direct `mailto:` action card with 24-hour turnaround indicators and professional network links.
